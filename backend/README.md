# Go-бэкенд

HTTP API и WebSocket для чата. Сервис управляет гостевыми сессиями и аккаунтами с JWT, хранит историю в схеме `backend` PostgreSQL и сохраняет изображения в MinIO. Задачи и ответы агента передаются через RabbitMQ.

## Запуск

Подготовьте корневой `.env` и задайте `JWT_SECRET` по [общей инструкции](../README.md#запуск-с-чистого-окружения). Из корня репозитория запустите бэкенд и проверьте его доступность.

```sh
docker compose up --build -d backend
curl -fsS http://localhost:8080/health
```

При старте сервис применяет миграции из `internal/migrations`. `POST /request` принимает текст и изображения, а `/ws` доставляет готовый ответ. Для работы с моделью поднимите `ai-service` в том же Compose-проекте.

## Проверка

Из каталога `backend` выполните `go test ./...` и `go vet ./...`. Для локального запуска Go, примеров Postman и интеграционных тестов используйте [справочник API](API.md).
