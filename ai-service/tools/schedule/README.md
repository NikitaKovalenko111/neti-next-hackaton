# Расписание УУНиТ

## Сервис учебных групп

`groups_service.py` запускает локальный HTTP-сервис без дополнительных зависимостей.

```powershell
python groups_service.py
```

Запросы к сервису:

```powershell
Invoke-RestMethod 'http://127.0.0.1:8765/groups'
Invoke-RestMethod ('http://127.0.0.1:8765/groups?q=' + [uri]::EscapeDataString('1-1.1.1.-26А'))
Invoke-RestMethod 'http://127.0.0.1:8765/groups/13500'
```

`GET /groups` возвращает список групп. Параметр `q` ищет по названию без учёта регистра и ставит точные совпадения первыми. `GET /groups/<id>` возвращает одну запись. В ответе сохраняются поля источника, включая `group_id`, `group_title`, `faculty`, `course`, `filial_id` и `filial_title`. `group_id` можно использовать в запросах расписания.

Сервис загружает список при первом запросе и кеширует его на минуту. Неизвестный ID возвращает `404`, сбой источника возвращает `502`. Другой источник можно указать через `--source-url`. Для подключения API расписания УУНиТ нужно письменное разрешение разработчика согласно [правилам сервиса](https://schedule.uust.ru/privacy).

## Расписание группы, преподавателя и аудитории

`schedule_lookup.py` загружает расписание УУНиТ и выводит JSON в UTF-8. Дополнительные пакеты не нужны.

```powershell
python schedule_lookup.py group --name 'ИВТ-ИВС-104Б' --date 2026-11-17
python schedule_lookup.py teacher --name 'Абади Ха Мостафа Самад' --week 12
python schedule_lookup.py room --name 409 --building-id 9 --week 12
python schedule_lookup.py room --name 110 --building 'Достоевского, д.131' --week 12
python schedule_lookup.py group --id 13700 --all
```

- `--id` работает для всех трёх типов. `--name` принимает название группы, ФИО преподавателя или номер аудитории. При нескольких совпадениях инструмент выводит варианты с ID.
- Для поиска аудитории по номеру укажите `--building-id` или `--building`. При поиске корпуса по названию по умолчанию используется головной вуз. Для филиала укажите `--organization-id`.
- `--date` выбирает один день, `--week` — учебную неделю, `--all` — весь учебный год. По умолчанию используется текущая неделя по времени Уфы. Для другого учебного года укажите соответствующие `--semester-id` и `--academic-year`. По умолчанию используются ID `241` и учебный год 2026/2027.
- `lessons` содержит занятия с датой, временем, предметом и остальными полями источника. Повторяющееся занятие выводится для каждой подходящей даты. Если занятий за период нет, `lessons` будет пустым массивом.
- Справочник преподавателей сохраняется в `.runtime/schedule.sqlite3` при первом поиске по ФИО. Он обновляется при следующем поиске спустя час или больше после последней загрузки. Расписание загружается при каждом запросе.

Для вызова из Python импортируйте `find_entity_id()` и `get_schedule()` из `schedule_lookup.py`.
