# Инструменты поиска по данным УУНиТ

Модели передаётся результат `tool_definitions()` в поле `tools` запроса OpenRouter API. Приложение выполняет выбранную функцию через `await call_tool(connection, name, arguments, ...)` и возвращает результат модели. Для запросов pgvector передайте HTTP-клиент OpenRouter и имя модели, использованной при индексации. Точные запросы работают через PostgreSQL. [Формат вызова инструментов OpenRouter](https://openrouter.ai/docs/guides/features/tool-calling)

| Вопрос пользователя | Инструменты |
| --- | --- |
| Где филиал в Сибае, какой у него сайт? | `list_branches` с городом, названием или ID. |
| Где корпус №7 или общежитие №7? | `search_places` с типом и номером. Филиал можно уточнить по найденным вариантам. |
| Какой точный адрес, телефон или вместимость общежития? Как открыть карту? | `get_place` по ID объекта. Ответ включает опубликованные сведения, ссылки на источники и возможный конфликт адресов. |
| В Сибае есть общежития? В Кумертау предоставляют жильё? | `get_housing` по филиалу. Опубликованное число, подтверждённые адреса и сведения о партнёрском жилье возвращаются отдельно. |
| Покажи фото конкретного корпуса. | `list_photos` по ID объекта. По умолчанию возвращает проверенные привязки. Поле `photo_available` показывает, загружен ли снимок в MinIO. Для вероятных и относящихся к филиалу фотографий есть `include_unverified`. |
| Как найти объект по свободному описанию? | `search_campus_context` подбирает кандидатов через pgvector. Адрес и статус проверяются через `get_place`. |
| Какие есть основания для материальной помощи? Что указано в пункте 14? | `list_support_grounds` по номеру, ключевым словам, филиалу или без фильтра. |
| У меня умер родственник. Нужны деньги на лекарства. | `search_support_grounds` подбирает кандидатов по смыслу. Затем `get_support_ground` уточняет, кого касается основание и какие условия указаны в приказе. |
| Какие документы принести, каков срок и сколько могут выплатить? | `get_support_ground` возвращает точный список документов, сроки, вид суммы и страницы приказа. |
| Могу ли я подать заявление, если учусь платно или нахожусь в академическом отпуске? | `get_support_programs` возвращает общие условия, порядок подачи и рассмотрения. |
| Куда идти в Бирске? Можно ли подать онлайн? Где дают консультации? | `list_support_channels` по филиалу. Для дополнительных консультаций передайте `include_consultations: true`. |
| Что можно изучать в филиале? Какие экзамены нужны после школы или колледжа? | `get_admission_options` по названию, филиалу или кодам. Для экзаменов укажите `metric: "entrance_tests"` и категорию поступающего в `exam_scope`. |
| Где обучение стоит до 200 тысяч в год? Хватило бы 230 баллов в прошлом конкурсе? | `get_admission_options` с `metric: "tuition_fees"` или `"passing_scores"`, годом, формой и нужным порогом. Для сравнения передайте до пяти кодов. |
| Дадут ли баллы за ГТО или олимпиаду? Нужен ли медосмотр? | `get_admission_rules` с темой и кодом направления для медосмотра. |
| Есть ли дисциплина в плане набора 2026 года? Где найти учебный план? | `find_curricula` по коду, форме, году набора и названию дисциплины. |
| Как связаться с кафедрой? Кто возглавляет институт? | `find_university_contacts` по фамилии, должности, подразделению или филиалу. |
| Когда заканчивается приём документов? Когда заселение в Бирске? | `get_university_dates` с темой, годом и филиалом. Общие сроки приёма включаются при поиске по филиалу. |
| Какая академическая стипендия? Сколько получают первокурсники за высокие баллы ЕГЭ? | `find_scholarships` по виду выплаты или названию. |
| Есть ли паспорт доступности корпуса? Когда его построили? | `find_campus_details` по названию и филиалу с `purpose: "accessibility"` или `"history"`. |
| Где взять приказ по номеру или бланк заявления? Как оформить академический отпуск или пересдать экзамен? | `find_university_document_links` ищет опубликованные ссылки. `search_university_documents` находит аннотации к положениям с датами и ссылками. |
| Как найти другую карточку из архива и посмотреть её целиком? | `search_university_records` по категории и ключевым словам, затем `get_university_record` по найденному идентификатору. |
| Сколько бюджетных, платных или целевых мест было на направлении? | `find_admission_seats` по коду, филиалу, форме, году и виду места. Для аспирантуры подходят коды вида `1.4.4`. |
| Есть ли места для перевода, восстановления или перехода на бюджет? | `find_transfer_vacancies` по коду, курсу, форме и филиалу. Смотрите дату публикации сведений и тип финансирования. |
| Когда подавать документы, проходить экзамен или давать согласие на зачисление в магистратуру или СПО? | `find_admission_calendar` по уровню, кампании, форме, финансированию и году. |
| Куда подать заявление на общежитие, какие нужны документы и когда работает комиссия? | `find_housing_move_in` по филиалу и году. `procedure` показывает порядок, `sessions` — даты, время и место заселения. |
| Где взять справку, восстановить пропуск или настроить почту? Как перейти на бюджет, найти клуб, обмен, ВУЦ или ТОП-ИТ? | `find_student_resources` по теме и каталогу. Подробности карточки возвращает `get_university_record`. |
| Где здравпункт, библиотека, бюро пропусков или студенческий офис? | `find_campus_services` по типу, запросу и филиалу. `include_map=true` ищет точки для карты. |
| Есть ли сейчас свободная койка? Как узнать статус своего заявления? | `get_data_scope` возвращает даты снимков и темы, по которым в базе нет сведений. |

`call_tool` принимает только имена и аргументы зарегистрированных функций. Ответы имеют статусы `ok`, `not_found`, `unavailable`, `invalid_arguments` или `unknown_tool`. `not_found` означает, что для этих фильтров в данных нет записи. Сходство векторного кандидата оценивает совпадение текстов, а решение о материальной помощи принимает комиссия. Запросы выполняются в транзакциях PostgreSQL только для чтения. При нескольких одновременных вызовах выделяйте отдельное соединение каждому вызову.

## Запуск вручную

Из `ai-service` с установленными зависимостями:

```sh
python -m tools list
python -m tools call get_admission_options '{"codes":["01.03.02","09.03.03"],"metric":"tuition_fees","branch_id":"ufa","year":2026,"max_annual_rub":200000}'
python -m tools call find_curricula '{"reference_code":"01.03.02","entry_year":2026,"subject":"безопасность жизнедеятельности"}'
python -m tools call search_places '{"branch_id":"ufa","kind":"building","number":7}'
python -m tools call search_support_grounds '{"query":"нужны деньги на лекарства"}'
```

CLI использует настройки `RAG_POSTGRES_*` и `OPENROUTER_*`. В Compose после импорта данных те же команды запускаются с настройками `rag-index`:

```sh
docker compose run --rm --no-deps rag-index python -m tools call \
  get_support_ground '{"ground_id":"death_of_close_relative","branch_id":"ufa"}'
```
