# Инфраструктура

Эти сервисы запускаются из корневого `docker-compose.yml`. Адреса и переменные окружения указаны в [общей инструкции](../README.md#запуск-с-чистого-окружения).

| Сервис Compose | Назначение |
| --- | --- |
| `postgres` | PostgreSQL 16 с pgvector. Схема `backend` хранит аккаунты и историю, схема `rag` содержит базу знаний и векторы. |
| `postgres-init` | Готовит схемы и роли. Переносит известные таблицы бэкенда из `public` в `backend`. [SQL подготовки](postgres/schemas.sql) |
| `rabbitmq` | Брокер задач `agent_requests` и ответов `agent_responses`. Панель управления по умолчанию доступна на `http://localhost:15672/`. |
| `minio` | Хранит изображения. Браузер получает файлы по подписанным ссылкам через Nginx. [Dockerfile MinIO](minio/Dockerfile) |
| `rag-index` | Применяет миграции базы знаний и рассчитывает недостающие эмбеддинги. [Индексация](../ai-service/REFERENCE.md#справочник-кампуса) |
| `campus-photos` | Загружает фотографии кампуса в MinIO и сохраняет ключи объектов в PostgreSQL. |

После запуска `postgres-init`, `rag-index` и `campus-photos` должны завершиться с кодом `0`. Проверить их состояние можно командой `docker compose ps --all`.
